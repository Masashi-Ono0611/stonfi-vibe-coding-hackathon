# STON.fi Vibe Coding Hackathon

## Overview

- **Dates**: April 16 (Thu) - April 20 (Mon), 2026
- **Seats**: 25 participants
- **Application**: Selection-based (commitment-focused)
- **Format**: Solo or team (any size). Team members must DM organizer (@cupcake_atarian) with Telegram handles
- **Theme**: Build a real TON product using AI coding agents with STON.fi integrations
- **Beginners welcome**: No coding experience required

Use STON.fi DEX SDK, Omniston SDK, or API.

### Tonstakers Track Qualification
Use Tonstakers SDK.

## Submission Requirements

- Project name
- One-liner + short description
- AI tools and integrations used
- GitHub repository (accessible)
- Live product URL (**deployed**)
- Demo video (Loom, max 5 min): what it does, who it's for, main flow, integration used

### Rules
- **Submissions are final** - double-check all links before submitting
- **Late submissions may not be reviewed**
- Existing projects can be extended, but judged work must be **new work done during the hackathon**
- Other chains/tools allowed, but **TON must be a core part** of the product
